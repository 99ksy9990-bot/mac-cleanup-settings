# GPT · 제미나이(나노바나나) 이미지 생성

API가 아니라 **브라우저에 로그인된 계정**으로 이미지를 만든다.

## 브라우저 규칙

- 브라우저 작업은 **어사이드(Aside) 브라우저를 우선** 사용한다.
  - 어사이드는 "사용할 브라우저"라는 뜻이다. 어사이드 안의 AI 기능으로 작업하라는 뜻이 아니다.
  - Claude가 쓸 수 있는 브라우저 제어 도구(브라우저 확장, 컴퓨터 사용 등)로 어사이드 창을 조작한다.
- 어사이드를 쓸 수 없을 때만 Chrome, 그다음 Edge 순으로 쓴다. 다른 브라우저로 바꾸면 사용자에게 한 줄로 알린다.
- 로그인은 사용자가 직접 해 둔 세션을 쓴다. 비밀번호를 입력하거나 저장하지 않는다. 로그아웃돼 있으면 멈추고 로그인을 부탁한다.

## 서비스

| 이름 | 주소 | 비고 |
|---|---|---|
| GPT 이미지 | https://chatgpt.com | 새 채팅에서 이미지 생성 요청 |
| 나노바나나 (Gemini) | https://gemini.google.com | 새 채팅에서 이미지 생성 요청. 모델 선택이 있으면 이미지 모델(나노바나나)을 고른다 |

## 순서

1. 무엇을 그릴지, 어느 쪽으로 만들지(GPT / 나노바나나 / 둘 다) 확인한다. 말이 없으면 **둘 다** 만들어 비교한다.
2. 프롬프트를 정리한다. 한국어 요청은 그대로 넣어도 되지만, 글자가 들어가는 이미지는 넣을 문구를 따옴표로 정확히 적는다. 비율(1:1, 16:9, 9:16 등)을 명시한다.
3. 어사이드에서 각 서비스의 **새 채팅**을 열고 프롬프트를 넣어 생성한다. 둘 다라면 탭을 나눠 동시에 돌린다.
4. 생성이 끝날 때까지 기다린다. 오류나 사용량 제한 문구가 나오면 그대로 사용자에게 전한다.
5. 결과 이미지를 원본으로 다운로드한다.
   - 저장 위치: `~/Documents/04_디자인/AI이미지/` (Windows: `%USERPROFILE%\Documents\04_디자인\AI이미지\`)
   - 파일 이름: `주제_gpt.png`, `주제_nanobanana.png` (같은 이름이 있으면 `_2`, `_3`)
6. 사용자에게 두 결과를 보여 주고, 수정할 점이 있으면 같은 채팅에서 이어서 수정 요청한다(새 채팅을 열면 맥락이 사라진다).

## 하지 말 것

- 유료 결제, 요금제 변경, 계정 설정 변경은 하지 않는다.
- 사용자가 요청하지 않은 공유 링크 생성·게시는 하지 않는다.
